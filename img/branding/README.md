# Ferros-Grynn — логотип и иконки

Утверждённый кристалл без вложенного графа. `Ferros-` — железный тёмный цвет, `Grynn` — рыжий цвет рёбер. Сохранены вертикальная и горизонтальная композиции; кристалл также доступен отдельно.

## SVG — основные файлы

- `svg/logo-vertical.svg` — знак над надписью.
- `svg/logo-horizontal.svg` — знак слева от надписи.
- `svg/icon.svg` — отдельный кристалл, квадратное поле.
- `svg/icon-light.svg` — светлые железные грани для тёмного фона, рыжие грани сохранены.

SVG содержат настоящие векторные контуры и грани. Надпись преобразована в контуры: установка шрифта не требуется. Все SVG имеют прозрачный фон, включая промежутки между гранями и просветы букв. При переводе растрового эскиза в вектор мелкая текстура заменена плоскими оттенками граней.

## PNG

Размер в имени файла — ширина в пикселях. Пропорции сохраняются.

| Каталог                | Размеры                                                                                    |
|------------------------|--------------------------------------------------------------------------------------------|
| `png/logo-vertical/`   | 256, 512, 1024, 2048, 4096; квадратные изображения                                         |
| `png/logo-horizontal/` | 384, 512, 1024, 2048, 4096; горизонтальные изображения                                     |
| `png/icon/`            | 16, 20, 24, 32, 40, 48, 64, 96, 128, 180, 192, 256, 384, 512, 1024; квадратные изображения |
| `png/icon-light/`      | 16, 20, 24, 32, 40, 48, 64, 96, 128, 256, 512; квадратные изображения                      |

Все экспортированные PNG — RGBA с прозрачностью. Они отрисованы из SVG; увеличение до 4096 px не является растягиванием растрового эскиза.

## Windows

- `ico/ferros-grynn.ico` — исходные цвета, для меню «Пуск», ярлыков и светлого трея.
- `ico/ferros-grynn-light.ico` — для тёмного трея.

Каждый ICO содержит размеры 16, 20, 24, 32, 40, 48, 64, 128 и 256 px с альфа-каналом. Для трея также доступны отдельные PNG 16–48 px. Вариант следует выбирать по фону интерфейса; автоматическое переключение этим набором файлов не реализуется.

## Сайт

`web/` содержит `favicon.svg`, многоразмерный `favicon.ico` (16, 32, 48, 64), PNG 16 и 32 px, `apple-touch-icon.png` 180 px и PNG 192/512 px. Все изображения прозрачные. Платформа может сама добавлять фон или маску при показе установленной иконки.

Для сайта файлы можно скопировать в публичный каталог и подключить:

```html
<link rel="icon" href="/favicon.svg" type="image/svg+xml">
<link rel="icon" href="/favicon.ico" sizes="any">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
```

## Проверка

Проверены размеры и альфа-каналы всех 36 PNG, прозрачные углы, содержимое трёх ICO, отсутствие растровых вставок и зависимостей от шрифтов в SVG. Малые размеры просмотрены на светлом и тёмном фоне. `manifest.json` содержит фактические размеры файлов.

`preview.png` — отдельный лист проверки с непрозрачными светлым и тёмным фонами; он не является логотипом и не входит в архив поставки. `sources/` хранит прозрачные результаты imagegen и промпты; основные файлы для использования находятся в `svg/`, `png/`, `ico/` и `web/`.

Файлы не подключались к приложению, установщику или сайту. Отображение в реальном меню «Пуск», трее и браузерной вкладке не проверялось.
